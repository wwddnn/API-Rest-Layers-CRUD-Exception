## 📌 Sobre o Repositório

Este repositório foi criado para organizar o código sobre o assunto API REST - Layers - CRUD - Exception

O objetivo principal é documentar:
* 💡 Como criar e gerenciar uma API REST usando Java e Spring Boot.
* 🎯 Criar os métodos mais usados por uma API REST (GET, POST, PUT DELETE).
* 💻 Foco nas boas práticas de código, e estruturar a aplicação usando a arquitetura em camadas (Controller, Service, Repository e DTO - Data Transfer Object) para melhor organização de responsabilidades e manutenibilidade do código.
